# GapAnalysisopen

واجهة عربية لاستكشاف فجوات الخدمات المرتبطة بتشغيل الشباب وإعداد موجز فرص للمستثمرين المحليين والدوليين.

## التشغيل

شغّل خادم ملفات محليًا من مجلد المشروع:

```sh
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000` في المتصفح. يلزم اتصال بالإنترنت لتحميل الخريطة والبحث الجغرافي.

## مصادر البيانات

- خرائط الأساس والبيانات الجغرافية: OpenStreetMap.
- البحث عن المواقع: Nominatim.
- المرافق: Overpass API.
- قائمة الدول والعواصم: CountriesNow API، مع عرض أسماء الدول بالعربية.

يختار المستخدم دولة، ثم يستخرج التحليل المرافق المصنّفة داخل حدودها الجغرافية كاملة. تُوزّع نقاط شبكة على كامل المضلع لتقدير تغطية خمسة قطاعات شبابية، ويُعدّ الموقع فجوة إذا لم يجد مرفقًا من القطاع ضمن 25 كم. هذا مسح مكاني تقريبي على مستوى الدولة، وليس فحصًا لكل متر أو قياسًا للطلب السكاني أو الجدوى المالية. قد تستغرق استعلامات Overpass الوطنية وقتًا طويلًا أو تتجاوز حدود الخدمة، وقد تكون بيانات OSM ناقصة؛ ينبغي التحقق الميداني قبل أي قرار استثماري.

الموجز المصدّر محليًا بالعربية، وللمستثمر الدولي بالعربية والإنجليزية. لا تتصل الواجهة بمصادر تمويل أو سجلات مستثمرين، ولا تحفظ طلبات تواصل.
